# Healthcare Appointment & Patient Portal

## Problem Statement
The project is a healthcare appointment and patient portal designed to manage patient registration, appointment details, and health information in a simple and organized way.

## Patient Registration Form
- Patient Name
- Email
- Mobile Number
- Date of Birth
- Gender
- Blood Group
- Department
- Doctor Selection
- Appointment Date
- Appointment Time
- Address
- Symptoms / Health Concern
- HTML5 Validation
- Bootstrap UI
- Register and Reset buttons
- Bootstrap cards for different sections

## Appointment Section
- Appointment ID
- Patient Name
- Department
- Doctor
- Date
- Time
- Appointment Status

## Health Information Section
